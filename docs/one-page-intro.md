# TaskMD Lite — One-Page Intro

## Tagline

**A Markdown-native CLI task manager that stays small on purpose.**

## Position

TaskMD Lite is not the raw script anymore.
It is the first **GitHub-worthy** version of the project.

## What changes compared to the original script

- packaged as a real Python project
- installable as `tm`
- task data stored in `tasks.md`
- metadata hidden in HTML comments
- direct file editing officially supported
- repository structure split into parser / storage / services / commands

## What stays simple

- no sidecar files
- no export system
- no AI
- no cloud / remote backends
- no connector ecosystem
- no academic / finance / commute / weather features

## Lite promise

You still get a tool that feels close to the original spirit:

- local
- readable
- keyboard-friendly
- hackable
- not overbuilt

## The user it serves

Someone who wants a proper CLI task manager project, but still values minimalism more than ambition.
