# TaskMD Lite Overview

## What Lite really is

TaskMD Lite is the **early productized version** of the original task script.

It keeps the scope intentionally small, but it already makes the crucial jump from:

- ad-hoc script

to

- structured Python project

## Core idea

Lite answers a practical question:

> If we take the original script seriously as a GitHub project, what should the first maintainable version look like?

## Lite design goals

1. package the tool properly
2. move storage out of the current working directory
3. replace custom TXT with Markdown-native storage
4. support editor-first workflows
5. keep the repository small and understandable

## Lite is for people who want

- a real Python package
- readable Markdown storage
- minimal but clean project structure
- direct editing in VS Code / Obsidian / Vim
- none of the later ecosystem complexity
